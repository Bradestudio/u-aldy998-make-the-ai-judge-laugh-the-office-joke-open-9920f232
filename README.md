## The line

> I set my status to 'in a meeting' so I could eat lunch in peace — now I'm in a meeting about why I keep setting my status to 'in a meeting'.

140 characters. Why this line wins, against the judge's five criteria, in the judge's own order:

1. **On-subject** — it *is* a one-line joke about office life, not a complaint. The setup is the chat status everyone fakes to get a quiet lunch, and the punchline is a meeting about the status itself.
2. **A real laugh on first read, with a surprising turn** — the reader expects the fake status to buy peace; instead it breeds the very thing it was dodging. The misdirection (lunch in peace) pays off in the last few words (a meeting about the status).
3. **One clean line, 140 characters** — a single sentence, setup and punchline on one line, no rambling around it.
4. **Fresh** — no printer, no meeting-that-should-have-been-an-email, no reply-all, no Wi-Fi password on a Post-it, no coffee. The joke finds a specific office detail — the status indicator — and turns it on itself.
5. **Clear on first read** — every word is everyday office vocabulary ("status", "in a meeting", "lunch"), no reference the reader cannot follow, no explanation needed.

## Run

`main.ts` (Node 22, no network, no dependencies) writes the single entry line to `/output/entry.txt`:

```sh
node main.ts
cat /output/entry.txt
```
